# kiang.in

Website of Kiang Collective LLP: wildlife films and expeditions.

- The published site is the HTML in this folder, served by GitHub Pages.
- Pages are generated from `_build/` (content lives in `_build/data.py` and `_build/trips.py`).
  To change text, edit those files and run `python3 _build/build.py`.
- Styles: `assets/site.css`. Behaviour: `assets/site.js`. Fonts are self-hosted in `assets/fonts` (SIL Open Font Licence).
- Forms post to Formspree.
