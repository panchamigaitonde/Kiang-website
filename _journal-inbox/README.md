# Journal inbox

Drop notes and photos for the next Journal story here (or paste them to Claude in chat).
Once a month, the journal agent turns new notes into a draft story page and opens a pull request for Panchami to approve.

- Notes: a .txt or .md file, any length, in your own words. Say where and when it happened.
- Photos: .jpg files. Mention the photographer's name in the notes if it isn't Panchami or Pradeep.
- After a story is published, its notes move to `_journal-inbox/used/`.

This folder is not published on the website.
